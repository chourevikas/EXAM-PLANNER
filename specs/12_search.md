# Module 12: Search

## Overview
A global search functionality allowing users to quickly find content across the platform.

## Searchable Entities
- **Questions**: Find specific PYQs or MCQs by keyword.
- **Topics & Subjects**: Quickly navigate to specific areas of the syllabus.
- **Resources**: Find PDFs, videos, and links.
- **Notes**: Search within saved or platform-provided notes.
- **Tests**: Find specific mock tests or past attempts.

## Additional Notes
- Must support keyword search.
- Ideally supports filtering (e.g., search only within "Indian Polity").
