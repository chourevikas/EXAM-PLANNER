# Module 8: AI Analysis

## Overview
Provides deep insights using AI after the user completes interactive sessions like Mock Tests or PYQ practice.

## Core Triggers
AI Analysis runs after every:
- Mock Test completion
- PYQ Session completion

## Outputs Provided
- **Strengths**: Highlights what the user did well.
- **Weaknesses**: Identifies knowledge gaps based on incorrect answers or high time-taken.
- **Recommended Revision**: Actionable suggestions on what to revise next.
- **Next Topics**: Topics the user is ready to tackle next.
- **Difficulty Analysis**: How the user performs across EASY, MEDIUM, and HARD questions.
- **Estimated Rank**: AI prediction of the user's standing.
- **Confidence Score**: AI's certainty metric on the user's readiness for the exam.
