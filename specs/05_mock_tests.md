# Module 5: Mock Tests

## Overview
Allows users to take various types of tests to evaluate their preparation, structured to simulate the real exam or test specific knowledge.

## Test Types & Generation
- **Full Syllabus Mocks (Mock 1)**: Covers the entire syllabus. Questions are AI-generated based on exact exam level and pattern matching, or pulled from curated mock papers.
- **Topic-Based Mocks (Mock 2)**: For topics the user has just studied. Questions are AI-generated to match the current pattern and level.

## Practice Tests (Separate from Mock Tests)
- **Overview**: Practice Tests are meant for casual learning and drill practice.
- **Rules**: 
  - There is no limit on the number of practice questions.
  - Performance here **does not affect** the user's overall analytics, rank, or mock test statistics.
  - However, taking practice tests **does contribute** towards Mission and Target completions on the dashboard.

## Adaptive Difficulty (Topic-Based Assessments)
- When a user takes a topic-based assessment for the first time, the test **starts from basic/easy questions**.
- **Leveling Up**: As the user answers correctly, they cross a threshold that triggers the system to "level up" the difficulty, presenting harder questions (Adaptive Learning).

## Results & Evaluation
After completing a test, the user receives detailed feedback including:
- Accuracy
- Time Taken
- Rank (if applicable/comparative)
- Weak Topics identified
- Suggestions for improvement
