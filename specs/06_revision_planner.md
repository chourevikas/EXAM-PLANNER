# Module 6: Revision Planner

## Overview
Helps users retain information by scheduling regular and smart revision sessions.

## Core Features
- **Revision Cycles**: Automatically generates spaced repetition cycles (e.g., Revision 1, Revision 2, Revision 3).
- **Smart Reminders**: Notifies users when it is time to revise a specific topic.
- **Priority Based Revision**: Focuses on high-yield or critical exam topics first.
- **Weak Topic Revision**: Integrates with Analytics to prioritize topics where the user has shown low accuracy.
